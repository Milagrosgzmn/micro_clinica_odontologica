# Micro: Clinica Odontológica

El sistema busca brindar una solución de gestion para la clínica odontológica *“Sonrisa Feliz”*.

---

## Tecnologias

- **Java JDK 21**
- **Maven** como gestor de dependencias
- **JUnit** para test
- **DAO** patron para la capa de persistencia
- **Metodología Ágil** por sprints
